# Accessibility support and verification

FLAMES provides a first-focusable **Skip to content** link in both layout shells, a focusable main landmark, visible keyboard focus, named form controls and buttons, live save/error/result status, and structural headings/regions. Policy/address/service rows can be selected with Enter or Space; reorder controls have explicit names. The mobile course navigation is a modal dialog: focus stays inside, Escape closes it, the background becomes inert, and focus returns to the launch control. The network replay dialog retains its keyboard/reduced-motion behavior.

Light/dark text tokens and vendor accents were checked against actual surfaces; secondary text, locked lessons, topology badges, legacy reference screens and dark action buttons were corrected where contrast failed. Important state is also written as text rather than represented only by color. Reduced-motion CSS suppresses decorative transitions/animations; hardware-viewer behavior is described in the hardware performance guide.

`tests/browser/accessibility.spec.mjs` runs axe WCAG 2 A/AA and 2.1 AA checks over representative landing/account/course/module, all simulator UI families, expanded editors, reference pages, and instructor studio/classroom screens in both themes. It also verifies the skip link and mobile focus lifecycle. Policy interaction regressions exercise keyboard row selection. Automated checks are retained in both Chromium and Firefox CI workflows. `@axe-core/playwright` is a development-only dependency and is not shipped in student bundles.

These automated checks and local keyboard workflows are evidence for the covered states, not certification of every screen-reader/browser/device combination. For acceptance, use NVDA/Firefox or VoiceOver/Safari to navigate the sidebar, open a lesson, create a rule, read diagnostics, answer a knowledge check, open/close dialogs and use the hardware keyboard alternatives. Check 200% browser zoom, long authored text, touch targets and real-device WebGL behavior. Fix any newly discovered issue with a representative regression rather than excluding it from the scanner.
