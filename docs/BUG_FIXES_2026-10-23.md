# Internal bug fixes — 2026-10-23

## Confirmed fixes

| Area | Previous behavior | Result |
| --- | --- | --- |
| Web filtering | Mixed-case or trailing-dot domain names bypassed block matching | Domain and block-list entries are normalized, including subdomains and domain boundaries |
| Missing filter reference | An allow policy silently lost filtering if its profile was missing | Invalid profile references prevent that policy from matching |
| Static routing | A correct required route passed even with an incorrect preferred/equal-cost route | Competing effective routes fail; a lower-priority backup remains allowed; equivalent CIDR networks compare consistently |
| Authentication | Login and registration shared a 20-request IP quota, including successes | Login identities have separate limits; successful logins release reservations; registration and network abuse budgets remain separate; 429 includes Retry-After |
| Progress | Arbitrary IDs inflated account/roster counts and could enter local caches | A shared public lesson registry validates submissions and filters stored/cache reads; curriculum alignment is tested |
| Interface masks | Only seven dotted masks normalized correctly | Every contiguous IPv4 netmask from /0 to /32 and slash prefixes are supported |
| Submissions | Nested fields were cast without validation; duplicates silently overwrote entries | Nested shape, enum, boolean, identity uniqueness, and collection limits are checked before grading |
| FortiGate async grading | Old responses could overwrite results after changing a lesson/configuration | Policy/interface/port results are invalidated on edits/navigation; stale responses are ignored |
| Palo Alto interfaces | MGT could pass with a data-plane interface type; old results/hints remained after edits | MGT requires the management type and no security zone; edits clear results and invalidate pending hints |
| Model API | Compatibility model endpoint searched obsolete root/wrong sibling paths | Endpoint uses the canonical frontend public asset path |
