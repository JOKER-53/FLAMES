# Upgrade review — 2026-10-02

- Server-saved completion for both vendors; guest practice retained; account cache isolation, monotonic merges, rapid-update safety, and visible synchronization errors.

## Automated checks

`npm run verify` passed: 39 engine/cable/PAN/render-smoke tests and 16 backend tests (55 total), backend/engine TypeScript builds, and frontend TypeScript plus production build. The suite covers account isolation, role enforcement, cookie flags, progress persistence, malformed requests, question consumption, and graceful AI unavailability as well as exercise semantics.

Frontend smoke tests render components without executing DOM effects; they are not interactive browser tests. Production Compose and Nginx syntax checks were also run. No Playwright or additional browser installation was used.

## Boundaries

This is a training simulator, not a real firewall or certified exam platform. Completion is browser-reported. Some exercises/reference tools still grade locally; account-saved configuration drafts, password reset/email/MFA, multi-classroom administration, and full vendor dataplane parity are not implemented. See [roadmap](ROADMAP.md) and [deployment](DEPLOYMENT.md).

No GitHub push, live deployment, broad cache cleanup, or deletion of unrelated user data was performed. The temporary Nginx validation container removed itself. Production image builds remain unverified locally to avoid large downloads.
